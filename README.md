# Be A Legend

Mobil öncelikli, karar odaklı futbolcu kariyer simülasyonu.

## Faz 1

- Ayrıntılı futbolcu oluşturma ve üç başlangıç kulübü
- Gün, enerji, moral, form ve kondisyon döngüsü
- Beş antrenman seçeneği ve özellik gelişimi
- Kadro rolü ve teknik direktör güveni
- Üç kritik kararlı interaktif maç sistemi
- Sezon istatistikleri, sözleşme ve transfer teklifleri
- Tarayıcıda otomatik kariyer kaydı

Projeyi çalıştırmak için `index.html` dosyasını açabilir veya basit bir statik
sunucu kullanabilirsiniz:

```bash
python3 -m http.server 8080
```
